# Design (Figma) - RNF01

**Status: will be done.** O arquivo de Figma ainda esta em desenvolvimento.

RNF01 nao tem tela propria - e um criterio aplicado a todas. O que o Figma
precisa entregar para sustenta-lo:

- Um quadro de estados vazios reunindo todos os "ainda nao ha nada aqui" da
  plataforma (console antes da primeira execucao, formas de onda sem `.vcd`,
  lista de projetos vazia, busca sem resultado), para que tenham a mesma
  estrutura: o que e este espaco, por que esta vazio, o que fazer agora.
- Um quadro equivalente para os estados de erro.
- Hierarquia visual do caminho principal: o que precisa ser encontrado sem
  procurar, e o que pode exigir procurar.
- Definicao de densidade: espacamento, tamanho de fonte e alvo de clique
  confortaveis para quem nao e usuario avancado.

Alem dos frames, RNF01 depende de uma decisao de conteudo que o design ajuda a
fixar: o vocabulario. Termos como "design", "testbench", "modulo de topo",
"compilar", "simular", "forma de onda" precisam ter uma unica traducao usada em
toda a interface.

Quando o arquivo estiver pronto, substituir este documento pelo link dos frames e
pelo glossario.
